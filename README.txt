3D Image Tool for OBS
---------------------

How to use:
1. Open index.html in your browser.
2. Upload or drag & drop a JPEG/PNG image.
3. The tool resizes it to 800x800 and shows a 3D spinning preview.
4. Click "Download OBS HTML" to save a self-contained obs-3d-image.html file.
5. Upload that file to GitHub Pages or any web host.
6. Use the hosted URL in OBS Browser Source for a permanent spinning 3D image.
